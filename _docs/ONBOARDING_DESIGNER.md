# 🎮 Nymora — Guide de démarrage (alpha)

Bienvenue ! Voici comment lancer le jeu et créer ton compte. Aucune compétence technique requise.

---

## 1. Installation

1. **Dézippe** le dossier que tu as reçu (clic droit → "Extraire tout") quelque part de simple, par ex. sur ton Bureau.
2. Ouvre le dossier extrait.

> ⚠️ Garde tous les fichiers ensemble dans le dossier. Ne déplace pas `Nymora.exe` tout seul, il a besoin des autres fichiers à côté.

---

## 2. Lancer le jeu

1. Double-clique sur **`Nymora.exe`**.
2. Windows peut afficher un avertissement bleu **"Windows a protégé votre PC"** (parce que le jeu n'est pas encore signé, c'est normal en alpha).
   - Clique sur **"Informations complémentaires"**
   - puis sur **"Exécuter quand même"**
3. Si ton antivirus râle, autorise `Nymora.exe` (faux positif classique sur les builds non signés).

---

## 3. Créer ton compte

Au lancement, tu arrives sur l'écran de connexion.

1. Remplis :
   - **Email** (n'importe lequel, même fictif, ex. `tonpseudo@nymora.fr`)
   - **Mot de passe** (minimum 8 caractères)
   - **Pseudo** (3 à 20 caractères — c'est le nom que les autres verront)
2. Clique sur **"Register"** (= s'inscrire).
3. Le message "Inscrit + connecte" apparaît, et un bouton vert **"Entrer dans le hub"** s'affiche.
4. Clique sur **"Entrer dans le hub"** → tu arrives dans le monde.

> 🔁 **Les fois suivantes** : ton compte est mémorisé. Tu peux soit cliquer directement "Entrer dans le hub", soit te reconnecter avec **"Login"** si besoin.

---

## 4. Dans le jeu

- **Se déplacer** dans le hub : clic sur les cases
- **Chat** : écris en bas, visible par tous les joueurs connectés
- **Défier un joueur** / **combattre** : clique sur un autre avatar pour ouvrir le menu
- **Deck Builder / Arène** : boutons en bas de l'écran

---

## 5. En cas de souci

| Problème | Solution |
|---|---|
| "Backend injoignable" au démarrage | Le serveur est peut-être en maintenance. Préviens Lorenzo. |
| Le jeu ne se lance pas | Vérifie que tous les fichiers du zip sont bien ensemble dans le même dossier. |
| Windows bloque le .exe | "Informations complémentaires" → "Exécuter quand même" (voir étape 2). |
| Pseudo déjà pris | Choisis-en un autre au Register. |

Pour tout bug ou retour de gameplay : note ce que tu faisais au moment du problème et envoie-le à Lorenzo. 🙏

Bon jeu chef ! 🗡️
